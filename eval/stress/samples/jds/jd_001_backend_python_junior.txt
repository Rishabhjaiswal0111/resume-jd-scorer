Junior Backend Engineer
Riverstone Partners · Bengaluru · Fully on-site · Full-time

Riverstone Partners builds products for the fintech payments sector. We are a team of 120 people with offices in Bengaluru.

About the role

• Work with product to scope features
• Own services end to end from design to on-call
• Write automated tests and review code
• Improve reliability and observability of services

Qualifications
- 0-2 years of experience in backend engineering
- Python
- REST API design
- PostgreSQL
- automated testing (pytest)
- Bachelor's degree in Computer Science or equivalent experience
- AWS
- Docker
- event-driven systems (Kafka)

Bonus points if you have
- Go
